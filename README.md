# Carsharing / Rental API

Это упрощённая модель сервиса для краткосрочной аренды автомобилей: пользователь через приложение находит свободную машину, бронирует её и фиксирует параметры поездки, а оператор управляет автопарком и обрабатывает нестандартные ситуации.

---

### О системе

В основе — модель self-service: человек не просто арендует машину, а взаимодействует с системой на каждом этапе. При завершении поездки фиксируются фактические показатели (пробег, уровень топлива), проверяется статус автомобиля и решается вопрос с депозитом.

Ключевые механизмы:

- поиск и фильтрация свободных автомобилей;
- управление статусами («доступен», «в аренде», «на обслуживании»);
- учёт пробега и уровня топлива при старте и завершении поездки;
- механизм работы с депозитом (блокировка → списание / возврат).
